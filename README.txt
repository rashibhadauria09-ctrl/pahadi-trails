PAHADI TRAILS - PROJECT FILES

FILES
1. index.html  - Website structure and content
2. style.css   - Layout, colours, responsive design and image styling
3. script.js   - Mobile menu, search/filter, trek detail popups, trip planner and checklist progress

HOW TO RUN
1. Keep all three files in the same folder.
2. Double-click index.html to open it in Chrome or another browser.
3. Internet is needed for Google Fonts and the online background photographs.

HOW TO EDIT
- Edit text and sections in index.html.
- Edit colours and design in style.css. Main colours are at the top inside :root.
- Edit interactive behaviour and trek guide information in script.js.

GITHUB PAGES
1. Create a GitHub repository (for example, pahadi-trails).
2. Upload index.html, style.css and script.js to the repository root (not inside an extra nested folder).
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, branch main, folder /(root), then Save.
5. Wait for the published website link to appear.

IMPORTANT CONTENT NOTE
Distances, altitudes, durations and seasonal guidance are approximate planning information. Confirm current route status, weather, permissions, yatra registration and local instructions from official authorities before travel. This student project is not a live safety or booking service.
